# echo — round 0 design targets

Design target pictures only. No site code changes.

## Baseline review

Inspected the live home, /posts/points-left-on-the-table, and /projects at 1440×900 and 390×844 on November 5, 2026.

The space identity and terminal navigation are useful foundations. The character artwork uses coarse, conspicuous marks rather than dense tonal detail. Metadata and dotted rules are faint, and the typography gives the content little variety or editorial character. The home artwork precedes the feature on mobile, delaying the writing. Projects have a long, uniform list treatment. The footer's two links and planet fragment do not establish a deliberate ending.

## Directions

- A — Engraved observatory: fine guilloche contours, confident grotesk type, and a ruled editorial grid. The footer expands the engraved planet into a panoramic horizon.
- B — Character field: literary serif headings and full-width project rows. Tiny characters model the planet, rings, and rocket with tonal density.
- C — Light-trail finish: calm grotesk typography and a smaller hero illustration. Purple orbital trails provide the visual crescendo at the foot of the page.

## Files and validation

Each PNG has an adjacent Markdown prompt record with route, generation instructions, any correction instructions, and native/export dimensions. All routes are the home page; footer files show its ending.

All nine images were generated with the built-in image tool. No API key, HTML mockup render, text overlay, or site-code substitute was used. Copy was visually checked. The initial A phone layout and B desktop Lexicon year needed retries. A phone received a further accent-color correction.

The tool ignored exact pixel dimensions and chose its own native raster sizes. Final exports use proportional resampling to 1440px desktop width and 390px phone width. Footer exports fit the entire generated frame inside 1440×600 with minimal near-black padding. Native size and exact export size are recorded beside every image. Phone pictures are compact full-page compositions; treat them as visual direction rather than a specification for production font sizes.
