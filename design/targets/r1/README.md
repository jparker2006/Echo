# echo — round 1 design targets

Six raster pictures only, generated with the built-in image tool. No site code changed. Route `/`; footer pictures are close-ups of its ending.

M1 uses a Hail Mary-inspired petrol/cyan and orange art treatment. M2 is a colour-only edit retaining B’s violet base with Hail Mary accents. Both combine A’s engraved ringed world and line fields, C’s sweeping orbital trails, and B’s straight-up rocket launch and serif editorial typography.

All nine r0 pictures were opened and studied before generation. Each final picture has an adjacent full prompt, references, generation/correction record, dimensions and validation note. palette.md records source access and six exact poster pixel samples.

All supplied words were checked visually in every final native picture; no copy overlays or HTML render was used. The first desktop footer was too tall and was regenerated as a shallow strip. The first footer close-up had an incorrect aspect ratio and was regenerated wide. The image tool chose its own pixel sizes: final files are proportionally resized to 1440px desktop width, 390px phone width and fitted within exactly 1440×600 for footer close-ups. Phone targets are compact full-page compositions, not production font-size specifications. Colour-only edits preserve the intended layouts; generative raster edits can introduce tiny antialiasing/detail differences.

No application tests apply to this picture-only change. Checks: visual copy/art review, PNG dimensions, Git diff scope, absence of site-code changes.
